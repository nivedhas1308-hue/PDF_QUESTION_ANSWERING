# PDF Question Answering System

## Objective
To build a PDF Question Answering System using LangChain,
ChromaDB and Ollama.

## Technologies Used
- Python
- LangChain
- ChromaDB
- Ollama
- Llama 3.2
- Nomic Embeddings

## Features
1. Extract text from PDF.
2. Split text into chunks.
3. Generate vector embeddings.
4. Store embeddings in ChromaDB.
5. Retrieve Top-5 relevant chunks.
6. Generate answers using RAG.
7. Compare normal and RAG answers.
8. Save results in CSV files.

## Model
Llama 3.2
